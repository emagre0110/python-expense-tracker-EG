# Python Expense Tracker

A simple command-line expense tracking application built with Python.

## Features

- Add new expenses
- View all recorded expenses
- Calculate total spending
- View spending totals by category
- Save expenses to a CSV file
- Load saved expenses when the program starts
- Validate user input for required fields and expense amounts

## Technologies

- Python
- CSV
- Git
- GitHub

## Skills Demonstrated

- Python programming
- Functions
- Lists and dictionaries
- File handling
- CSV reading and writing
- Input validation
- Data processing
- Basic data aggregation
- Source control with Git and GitHub

## How to Run

1. Clone the repository.
2. Open the project folder in Visual Studio Code or another code editor.
3. Open a terminal in the project folder.
4. Run:

```powershell
python expense_tracker.py
